# Claude Fable 5 — Instructional Presentation

A self-contained HTML slide deck that walks a user, step by step, through the
highest-leverage Claude Fable 5 use cases covered in the source video
([youtu.be/lplVBFr0Ndc](https://youtu.be/lplVBFr0Ndc) — *"Claude Fable 5 Use
Cases You Must Do NOW"*).

Open **`index.html`** in any browser. No build, no dependencies, no network.

## What's in it

1. Title + how-to
2. Agenda (the 5 use cases)
3. Content repurposing system
4. High-ROI SEO & page audit
5. Visual & UX critique
6. Reusable AI agent workflow
7. Big code work, done right
8. Recap / next steps

Each use-case slide has: numbered follow-along steps, a paste-ready prompt
(with a copy button), and a screenshot panel with a timestamp badge.

## Finishing it with the real video

The screenshot panels ship **empty on purpose** — nothing here is a fabricated
video frame. To complete the deck against the video:

- **Add a screenshot** — click a panel (or drag an image file onto it) to place
  the exact frame. This happens entirely in your browser; no upload.
- **Set the timestamp** — click the amber time badge on a panel and type the
  real time code (e.g. `04:12`).

> Note on how this was built: this environment's network policy blocks YouTube,
> so the video could not be downloaded here to auto-extract frames. The steps,
> prompts, and structure are grounded in the video's documented subject matter;
> the frames and exact timestamps are yours to drop in.

## Controls

- **← / →** (or the Prev/Next buttons) — move between slides
- **Home / End** — jump to first / last slide
- **Sun icon** (top right) — toggle light / dark
- **Print / Save as PDF** — the deck prints one slide per page
