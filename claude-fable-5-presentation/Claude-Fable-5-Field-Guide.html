Use case 01

Content repurposing system

01 / 05 use cases
Follow along — step by step

  1. Open a fresh Claude chat

    Start clean so the model isn't anchored to earlier context.

  2. Give it one strong source

    Paste a single blog post, transcript, or a clear idea — the raw material to spin out from.

  3. Name every output you want

    List the exact assets: social post, carousel outline, email, video hook, SEO metadata, FAQ.

  4. Run it in one pass, then refine

    Let Fable 5 produce the whole pack, then ask for tighter hooks or a different tone on any single asset.

Why it lands: Fable 5 is built to take one idea and expand it into a coherent set of assets in a single pass — the win is consistency across channels, not just speed.
Paste-ready prompt
Role: You are my content repurposing engine. Source: """[paste one blog post / idea]""" Produce, in one pass: • 1 LinkedIn post (hook + 3 short paras) • a 6-slide carousel outline • 1 marketing email (subject + body) • 3 short-form video hooks • SEO title + meta description • 5 FAQ questions with answers Voice: [brand voice]. Keep claims tied to the source.

Use case 02

High-ROI SEO & page audit

02 / 05 use cases
Follow along — step by step

  1. Provide the page + target keyword

    Give the URL (or paste the page copy) and the one keyword you want it to rank for.

  2. Ask for search intent first

    Have Fable 5 state what a searcher actually wants before proposing any changes.

  3. Request a prioritized fix list

    Titles, meta description, H1/H2 structure, internal links, and weak sections to rewrite — ranked by impact.

  4. Apply top fixes, then re-audit

    Make the highest-impact changes and run the same prompt again to confirm they hold.

Why it lands: An SEO audit is one of the highest-ROI recurring tasks — clear inputs (URL + keyword) turn into concrete, do-this-first edits you can bill or ship.
Paste-ready prompt
Role: Senior SEO auditor. Page: [URL or pasted copy] Target keyword: [keyword] Return, in priority order: 1. Search intent behind the keyword 2. Top 5 fixes, highest impact first 3. 3 title options + 1 meta description 4. Suggested H1 / H2 outline 5. Internal-link opportunities 6. The single weakest section, rewritten

Use case 03

Visual & UX critique

03 / 05 use cases
Follow along — step by step

  1. Screenshot the surface

    Grab the homepage, landing page, dashboard, or carousel you want reviewed.

  2. Attach it and set the goal

    Tell Fable 5 what the page is meant to do — sign-ups, purchases, clarity of message.

  3. Ask for a ranked critique

    Clarity, messaging, CTA placement, and what's confusing — each returned as a prioritized change.

  4. Iterate on the redesign

    Request a revised layout or copy for the top issue, then compare against the original.

Why it lands: Fable 5's visual analysis reads a screenshot the way a reviewer would — turning a vague "something feels off" into a specific, ordered punch-list.
Paste-ready prompt
Attach: [screenshot of the page] Role: Conversion-focused UX reviewer. Goal of this page: [e.g. free-trial sign-ups] Critique & rank by impact: • Message clarity in the first screen • CTA visibility & placement • Anything confusing or high-friction • 3 concrete changes, most important first

Use case 04

Reusable AI agent workflow

04 / 05 use cases
Follow along — step by step

  1. Pick a weekly-repeat task

    Something you already do every week: page audit, blog repurpose, or a business brief.

  2. Write it as a full spec

    Give Fable 5 a role, real context, clear steps, and a defined output format.

  3. Test, then lock the prompt

    Run it, tighten wording until the output is reliable, then save it as your reusable workflow.

  4. Re-run with fresh inputs

    Next week, swap only the inputs — the saved prompt does the rest, consistently.

Why it lands: Fable 5 rewards goal-oriented prompts you keep — turning a one-off chat into an asset you reuse is where the real time savings compound.
Reusable workflow skeleton
Role: [who the model should act as] Context: [standing facts about my business] Input: [the one thing that changes each run] Steps: 1. [first thing to do] 2. [second thing to do] 3. [verify against the goal] Output: [exact format — headings, length, tone] Save as: "[workflow name]" — reuse weekly.

Use case 05

Big code work, done right

05 / 05 use cases
Follow along — step by step

  1. State the goal, not the keystrokes

    Describe the outcome you want and the constraints — let Fable 5 plan the path.

  2. Turn effort up for hard work

    For migrations or refactors, raise the effort/thinking setting so it reasons more deeply.

  3. Ask for a verification loop

    Have it check its own work — run tests, re-read the diff, confirm nothing broke — before you accept.

  4. Review the diff, then ship

    Read the changes, spot-check, and merge. Scale up only once a small slice is proven.

Proof point: a codebase-wide migration across ~50M lines of Ruby that a team would take months to do by hand was reported finished in about a day — the pattern is goal + effort + verification, not micro-instructions.
Goal-oriented prompt shape
Goal: [the outcome, e.g. migrate X → Y across the repo] Constraints: [keep tests green, no API changes] Effort: high — reason before editing. Loop: 1. Plan the change and list affected files 2. Make edits in small, reviewable steps 3. Run tests + re-read the diff 4. Report what changed and what to verify
