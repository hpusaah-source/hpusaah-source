Prices are rough monthly list prices for a single user or a small team, gathered mid-2026. Check your own invoice — the number that matters is the one you're actually paying, times the number of seats.

Effort estimates assume a coding agent doing the typing and you doing the deciding. "A weekend" means a working version you'd actually use, not feature parity. Feature parity is never the goal — the reason self-built tools win is that they do the 20% you use and skip the rest.

Before you cancel anything: run it in parallel for a month, and make sure you can get your data back out of the thing you built. An app you can't export from is a subscription you pay for in maintenance.
